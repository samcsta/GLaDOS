# Herbie in GLaDOS

Herbie adapts [Savannah's herbie team](https://git.r3dt34m.net/spapp1/herbie/src/branch/sav), pinned to `6ccd27318d4467007407e8e1e4e6f3f8abb726a3`, as a native integrated team. Access to the upstream repository requires RT VPN. Source attribution and fingerprints are bundled in `references/HERBIE-PROVENANCE.md`. No explicit upstream license was present; this adaptation preserves attribution and does not assert new redistribution rights.

Open **Tools → Agents → Ford RT Agentic Teams** and choose **Install Herbie**. Optional teams are not installed or enabled at startup. Installation first verifies or installs TShark, then integrates and enables Herbie. Its **Herbie Agentic Team** tab appears beside **GLaDOS Agentic Team**, with its member agents and assignments for additional GLaDOS/custom specialists. The team and its members remain editable through Agents; saved instructions/model/effort settings are user-owned revisions. Source updates do not silently overwrite those edits. Jarvis and Chappie are reserved catalog entries until an integration is available.

The package includes Packet Inspector, Mechanic, Pain, Panic, Security, Red Teamer, DNS Specialist, Password Auditor, Planner, Researcher, Coder, DevOps and Reviewer, plus a GLaDOS Herbie Coordinator. Every member uses the selected/default GLaDOS model and medium effort initially; change individual settings in Agents. No `redllm` model mapping or Kilo runtime is required.

The shared evidence contract defines source IDs, claim classes, confidence, falsification and explicit missing evidence. The handoff protocol preserves those IDs through scoped native Agent calls. The incident playbook supports severity and recommendations for human owners. Independent review applies to a new substantive confirmed security finding, not routine queries or negative results. Default task budgets are instructions, not a new scheduler: four assignments, sixty total tool calls, one necessary review pass; each worker has a maximum of twelve calls unless the operator changes the budget.

Start a packet investigation by providing an existing capture path and the question/time window. Packet Inspector and DNS Specialist run `tshark -r` against that local file. TShark is a native downloaded command-line tool, not an additional MCP server. The installer reuses a working system TShark, including the official Wireshark app on macOS. Otherwise it uses Homebrew's CLI-only `wireshark` formula on macOS, or an existing Homebrew/standard distribution package manager on Linux. It never installs Homebrew or bootstraps a package manager itself. The installed executable is version-verified and its absolute path is exposed in agent shell environments, including GUI launches whose original PATH omits Homebrew.

On desktop Linux, an existing polkit authorization agent may show the system administrator dialog. There is no hidden terminal password prompt; without that agent, only already-authorized `sudo -n` is used. If permissions or a package manager are unavailable, installation fails with a terminal command to complete setup and retry. Package-manager work has a ten-minute limit; cancellation or setup failure does not install or enable the team. Linux elevated package managers also run under the system timeout utility. No capture groups, ChmodBPF, Npcap, live-capture permissions or drivers are explicitly enabled by GLaDOS. Dependency removal is separate from team removal because other applications may use TShark.

The integration does not bundle the upstream Python packet_harness modules, live monitor/profile/training services, capture drivers or hardware. No captures, prior case data, generated artifacts or corpus-specific thresholds learned from upstream captures are copied. General declared analysis thresholds remain hypotheses to check against the current case.

Tool installation references: [Homebrew CLI formula](https://formulae.brew.sh/formula/wireshark), [Ubuntu TShark package](https://packages.ubuntu.com/noble/tshark), [Fedora CLI package](https://packages.fedoraproject.org/pkgs/wireshark/), [Arch CLI package](https://archlinux.org/packages/extra/x86_64/wireshark-cli/), [polkit authorization behavior](https://polkit.pages.freedesktop.org/polkit/pkexec.1.html), and [TShark offline file mode](https://www.wireshark.org/docs/man-pages/tshark.html).

Most roles have Read/Glob/Grep only. Researcher also has WebSearch for documentation. Packet Inspector and DNS Specialist have Bash for scoped offline inspection. Coder and DevOps have Write/Edit/Bash for requested local implementation and relevant validation. Those shell tools remain subject to normal GLaDOS permission/safety gates; the manifest is not an OS sandbox. Herbie gets no MCP connector or privileged Full Access capability by default. The coordinator receives native Agent/Task delegation through the existing team runtime; workers cannot recursively delegate or reach unrelated specialists.

No automatic live captures, network assessment, ECU/vehicle actuation, security-access requests, containment, publication or sent communications are authorized by enabling this team. Evidence claims about safety domains require explicit gateway/ECU corroboration. Credential material stays redacted and case outputs are written only when requested to a selected writable location; managed package instructions stay immutable during tasks.
